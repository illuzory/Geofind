# Источники и воспроизводимость

## Координаты и Excel

Координаты всех площадок выбраны вручную для MVP с разрешения пользователя. Это приблизительные городские точки, не подтверждённые адреса размещения устройств. Сервис «Екатеринбург, ул. Буторина, 6» имеет условные координаты 56.8176, 60.6395; геокодирование адреса не выполнено.

Нижний Тагил, Каменск-Уральский, Серов: по 6 синтетических устройств; имена и серийные номера начинаются с DEMO. Публичная `demo_inventory.xlsx` содержит только синтетические устройства. Адаптированная пользовательская книга исключена из Git; оригинал не меняется.

## Дороги и граница

Natural Earth, public domain: https://www.naturalearthdata.com/about/terms-of-use/

- Дороги: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_roads.geojson
- Граница: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_1_states_provinces.geojson ; выбрана запись `iso_3166_2=RU-SVE`.

В каждом GeoJSON поле `metadata.source_sha256` фиксирует SHA-256 полного исходного файла. В репозитории сохранены готовые региональные данные: повторная загрузка для запуска не нужна. Дороги обрезаны по границе с буфером 0.8 градуса, чтобы сохранить соседние маршруты. Буфер не гарантирует наличие глобально оптимального реального маршрута. Обновление дорог возможно через `scripts/prepare_roads.py` с заранее загруженным исходным GeoJSON.

Natural Earth 1:10m — картографически обобщённая геометрия, а не современный маршрутизируемый OSM. Во всех исходных региональных сегментах тип дороги неизвестен, поэтому используется единая модельная скорость. Сеть нодируется по геометрическим пересечениям и считается двусторонней. Нельзя интерпретировать такой путь как навигационную инструкцию.

## Встроенные библиотеки карты

- Leaflet 1.9.4: https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.js и leaflet.css. Лицензия BSD-2-Clause: `assets/leaflet.LICENSE`.
- jQuery 3.7.1: https://cdn.jsdelivr.net/npm/jquery@3.7.1/dist/jquery.min.js . Лицензия MIT: `assets/jquery.LICENSE`.

Файлы загружены по HTTPS с проверкой TLS, сохранены локально и встроены в HTML. Подложка CartoDB опциональна; по умолчанию выключена. Никакой внешний CDN или геокодер для автономной карты не нужен.


## Проверенный OSRM

Автомобильная маршрутизация: https://router.project-osrm.org , публичный demo FOSSGIS/OSRM. Дорожные данные — © OpenStreetMap contributors, https://www.openstreetmap.org/copyright . Условия использования сервера: https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server .

Публичный сервер не сообщает версию графа и не гарантирует доступность/обновления. Наблюдения кэшируются с явным идентификатором OSRM_CACHE_NAMESPACE. Это версия наблюдения клиента, а не подтверждённая версия графа. Локальный дорожный сервер не установлен. Результаты реальной интеграционной проверки описаны в OSRM_VALIDATION.md.
