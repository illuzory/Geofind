## Автоматические тесты

60 passed, без предупреждений. Эти же 60 тестов прошли на распакованной копии итогового проекта; файл запуска app.py, данные и статические ресурсы включены. В дополнение к прежним проверкам маршрутизации/импорта:

- Согласуемые площадки исключаются из обоих частей дроби SLA и максимума, но сохраняют время доезда.
- При отсутствии стандартных площадок процент/максимум не применяются.
- Неизвестный тип не принимается; вычисляемые поля из файла не могут подменить результат.
- Три книги сохраняют ID, меняют все адреса и содержат 78/79/80 устройств, 2/3/2 согласуемые площадки.
- Формат/компоненты адреса, сокращения и типы улиц, разные дома, неоднозначные ответы, расхождение координат.
- Все 27 подготовленных адресов сверяются по сохранённым ответам без сети.
- Успех, отсутствие объекта, отсутствие проверки и отказ геокодера — разные состояния; координаты не исправляются автоматически.
- Атомарный импорт, сохранение после нового подключения, отказ от устаревшего конкурентного импорта и восстановление версии.

## Геокодер онлайн

Реально проверен Nominatim. Свободная строка с русскими «г.»/«д.» давала пустой результат для существующего дома; реализован поддерживаемый структурированный запрос street/city/state. Повторная проверка: Екатеринбург, проспект Ленина, 24А — status=verified, источник Online OSM/Nominatim, расхождение координат 0 м. Ключ кэша содержит версию формата запроса; старый отрицательный ответ не маскирует исправление.

Проверяется совпадение города/области, типа/названия улицы, дома и указанного индекса. Допуск координат 250 м. Несколько одноадресных POI одного здания допустимы, разнесённые объекты требуют ручной проверки. Индекс сверяется с OSM, не с официальным почтовым реестром. Дополнительно через браузер принудительно обновлены все 9 адресов исходной книги: 9/9 verified по свежим сетевым ответам, не по кэшу или встроенной справке. Отчёт online_address_checks.csv включён в snapshots; время отображается с часовым поясом Екатеринбурга (+05:00).

Выполнен полный сценарий:

Ошибок JavaScript нет. Повторное применение уже активной книги отключено; после успешного импорта интерфейс синхронизирует версию перед следующими действиями.
